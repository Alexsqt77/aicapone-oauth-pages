Privacy policy

Effective date: 6 October 2026

Overview

Aicapone is a private, non-commercial personal-assistant integration operated for a single user. This policy explains how the integration accesses and uses Google user data.

Google data accessed

Aicapone requests narrowly scoped access to:

  • Calendar events on the secondary Google Calendar created by the Aicapone application.
  • Google Drive files created by Aicapone or files the user explicitly opens for the integration.

The integration does not request access to unrelated personal calendars or unrelated Drive files.

How data is used

Google user data is used only to provide user-requested personal-assistant functions, including:

  • Creating, reading, updating, and deleting events on the app-created calendar.
  • Preparing calendar summaries and reminders.
  • Creating and maintaining a user-requested subscription-tracking spreadsheet.
  • Producing user-requested subscription and billing summaries.

Data sharing and advertising

Aicapone does not sell Google user data, share it with advertisers, use it for advertising, or provide it to data brokers. Data is not disclosed to third parties except when required by law or necessary to operate Google’s own APIs at the user’s request.

Storage and retention

Calendar events and spreadsheets remain in the user’s Google account. OAuth credentials are stored on the user-controlled Hermes Agent system and are used only to perform authorized requests. Access is retained until the user revokes it or removes the locally stored authorization.

Security

Aicapone uses least-privileged OAuth scopes and limits access to app-created or explicitly opened resources. No security measure can guarantee absolute protection, but access is kept as narrow as the integration’s functions allow.

User control and deletion

The user can revoke Aicapone’s Google access at any time from Google Account permissions. The user can also delete calendar events, spreadsheets, and other app-created data directly from Google Calendar or Google Drive.

Changes to this policy

This policy may be updated when the integration’s features or Google permissions change. The effective date at the top of this page will be revised when material changes are made.

Contact

Privacy questions can be submitted through the repository’s GitHub Issues page.
