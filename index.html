Private personal assistant integration

Aicapone

Aicapone is a private assistant operated for a single user. It helps manage an isolated calendar, reminders, briefings, and a subscription tracker while using narrowly scoped Google access.

What the integration accesses

  • 01Calendar events only on the secondary calendar created by Aicapone.
  • 02Google Drive files created by Aicapone or explicitly opened for the integration.
  • 03No access to unrelated personal calendars or unrelated Drive files.
